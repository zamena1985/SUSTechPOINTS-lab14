# Изменения относительно оригинала SUSTechPOINTS

Проект основан на [naurril/SUSTechPOINTS](https://github.com/naurril/SUSTechPOINTS), ветка dev-auto-annotate, состояние на 13.06.2024. Лицензия GPL-3.0 сохранена. Ниже перечислены все изменения, внесённые для лаборатории.

Изменения в коде SUSTechPOINTS (Claude, октябрь 2026). Оригиналы рядом: *.orig
- public/js/data.js: MaxWorldNumber 80 -> 20 (меньше памяти, не белеет экран)
- public/js/view.js, side_view_op.js, box_editor.js: сдвиг вида в окошках коробки
  правой кнопкой мыши (pan); двойной правый щелчок - вернуть к центру;
  при выборе другой коробки сдвиг сбрасывается.
Откат: скопировать backup/<файл>.orig поверх public/js/<файл>, Ctrl+F5 в браузере.
- public/js/editor.js: отмена/повтор. Ctrl+Z - отменить, Ctrl+Y или Ctrl+Shift+Z - повторить.
  Стек на каждый кадр (до 50 шагов), хранится до перезагрузки страницы; записывается
  перед каждым изменением (сдвиг, поворот, размер, класс, добавление, удаление, автоподгонка).
  Движение мышью в окошках коробки = один шаг (хуки undoBeginGesture/undoEndGesture в side_view_op.js).
  Кнопки ↶/↷ со счётчиком шагов в шапке (index.html, оригинал backup/index.html.orig);
  запасной перехват Ctrl+Z на window (если браузер глотает событие).
  Оригинал: backup/editor.js.orig
- Кеш браузера: адреса скриптов имеют версию (?v=...), для /static в server.conf выставлен no-cache.
  После любой правки в public\js запускать bump_version.bat, затем F5 в браузере (Comet игнорирует Ctrl+F5 для модулей).
  Оригиналы: backup/main.js.orig, save.js.orig, index.html.orig
- public/js/editor.js (handleSelectRect) + public/js/ml.js: новая коробка (Ctrl+ЛКМ выделение) сразу
  отрисовывается, не дожидаясь ответа нейросети авто-поворота; если предсказание упало,
  коробка всё равно остаётся и получает класс. Раньше при ошибке/задержке коробка не появлялась
  до смены кадра. Оригиналы: backup/ml.js.orig, box_op.js.orig.
  Цепочка версий расширена: editor.js -> box_op.js -> ml.js, box_editor.js -> ml.js.
- public/js/editor.js (render): mainView.render() -> mainView.renderAll(). Раньше при "неактивном" главном
  виде (режим пакетного редактора, фокус) кадр не перерисовывался, новая коробка появлялась
  только после движения камеры.
- public/js/floatlabel.js (coord_to_pixel): подписи коробок скрывались в жёсткой полосе у краёв экрана
  (x<-0.6 слева, x>0.9 справа) - объекты слева/справа оставались без подписи до поворота камеры.
  Теперь подпись скрывается только если её якорь реально за экраном; если якорь под открытой панелью
  окошек коробки (левые 320 px), подпись прижимается к правому краю панели, а не прячется.
  Оригинал: backup/floatlabel.js.orig
- public/js/editor.js: новая коробка (выделение Ctrl+ЛКМ) получает класс Infrastructure по умолчанию
  вместо угадывания по размеру (настройка this.DEFAULT_NEW_BOX_TYPE; null = угадывать как раньше).
- public/js/side_view_op.js: Q/E в среднем и нижнем окошках коробки поворачивают вокруг вертикали
  (как в главном окне). Раньше они наклоняли коробку вокруг горизонтальных осей - визуально
  "не реагировали" и заваливали стены (см. 885 на 63°). Наклон по-прежнему доступен через ручку в окошке.
- editor.js, side_view_op.js, box_editor.js: горячие клавиши (Q/E/W/A/S/D/R/F/G/V/T...) работают в любой
  раскладке - буква берётся по физической клавише (event.code), а не по символу. В русской раскладке
  Q давала 'й' и клавиши "не работали".
- box_op.js + editor.js: клавиша H - подгонка выделенной коробки инфраструктуры: стягивает стороны
  к точкам внутри коробки, ставит низ на землю, убирает наклон. Поворот (Q/E) не меняет. Правило
  "только уменьшать": размеры никогда не становятся больше нарисованных; стороны длиннее 15 м не трогает. Полная автоподгонка (угол+границы) отброшена: в плотной застройке
  затягивала соседние стеллажи.
- box_editor.js / view.js: сдвиг вида (pan) в окошках коробки сбрасывается при КАЖДОМ подключении
  коробки (раньше - только при смене на другую; при повторном выборе той же коробки рамка с ручками
  оставалась смещённой относительно объекта).
- public/js/lib/OrbitControls.js: если кнопку мыши отпустили вне холста (над окошками коробки,
  картинкой камеры), состояние вращения/сдвига застревало и колесо (масштаб) не работало до
  следующего клика. Добавлен сброс состояния на уровне окна. Оригинал: backup/OrbitControls.js.orig
- public/js/view.js: orbit.minDistance = 1.5 - камера не подлетает к цели вплотную (там зум "залипал").
- OrbitControls.js + editor.js: зум к курсору. Колесо "внутрь" переносит точку вращения камеры на
  ближайшую точку облака под курсором (hook orbit.pickPoint), скорость сдвига считается от расстояния
  до этой точки (не меньше 5 м). Раньше при цели, оставшейся далеко позади точек, зум и сдвиг
  "замирали" вблизи (скриншот с камерой внутри двора).
- README.md: гайд по разметке для лаборатории на русском (установка, экран, коробки, классы и правила ТЗ,
  порядок работы по сериям, ошибки проверки, клавиши). README авторов перенесён в doc/README_upstream.md.
  Картинки гайда: doc/guide/. PDF-версия: doc/guide_ru.pdf, собирается tools/build_guide.py
  (Markdown -> HTML -> печать в PDF через Chrome).
- Пакет обновления для уже установленных копий: tools/make_update.py собирает dist/SUSTechPOINTS-update.zip
  только из файлов программы (без data, без документации авторов). update.bat в корне: проверяет, что лежит
  в папке программы, обновляет пакеты Python, напоминает про Ctrl+F5. tools/findpy.bat: единый поиск Python
  для всех bat-файлов (папка python портативной версии, затем venv, затем .venv из инструкции куратора).
  Все bat-файлы в репозитории - CRLF (с LF cmd теряет позицию в файле после chcp 65001).
- Портативная версия: tools/make_portable.py собирает dist/SUSTechPOINTS-portable.zip со встроенным
  Python 3.10 (embeddable), пакетами точных версий из tools/portable_constraints.txt, моделью и примером
  сцены. start.bat в корне запускает программу (через run.bat и findpy). Обновляется тем же пакетом обновления.
- TensorFlow необязателен. algos/pre_annotate.py: если TensorFlow или модель недоступны (или задано
  SUSTECH_NO_TF=1), сервер запускается, а поворот новой коробки считается по геометрии точек
  (L-shape fitting по критерию прижатости, направление длинной стороны). С TensorFlow - нейросеть как раньше.
  install_tensorflow.bat ставит TensorFlow в текущую копию; tools/make_tf_addon.py собирает архив-дополнение
  SUSTechPOINTS-tensorflow.zip из разницы полной и облегчённой портативных сборок.
- Портативные сборки берут пакеты из рабочего окружения venv (tools/venv_dists.py: копирование по RECORD,
  замыкание зависимостей TensorFlow по метаданным), сеть нужна только для embeddable Python и get-pip.
  Файл путей встроенного Python содержит корень программы ("..") - иначе algos/ не импортируется.
  Проверено из чистой распаковки: облегчённая версия (108 МБ) - поворот по геометрии; после распаковки
  дополнения SUSTechPOINTS-tensorflow.zip (361 МБ) - нейросеть.
- Исправлены bat-файлы (run, check, transfer, bump_version, install_tensorflow): в строке вызова
  tools/findpy.bat вместо обратного слэша был управляющий символ, из-за чего start.bat и run.bat
  закрывались с ошибкой "tools не является командой". Вызов теперь по полному пути от папки скрипта.
  bump_version.bat вызывает tools/bump_version.py вместо встроенной однострочной программы.
- update.bat стал самостоятельным: сам находит папку программы (своя папка, рабочий стол, Загрузки,
  Документы, корни дисков, иначе спрашивает), скачивает свежий пакет с GitHub (releases/latest), распаковывает
  системным tar и копирует с заменой через robocopy; архив или распакованный пакет рядом использует без сети;
  отказывается работать при запущенной программе. Проверено: изнутри портативной папки и из чужой папки.
- Пакет обновления: в корне архива только update.bat, файлы программы в папке files/ - распакованный
  пакет больше не выглядит как вторая копия программы. update.bat понимает обе раскладки.
- Пакетный режим (V, несколько кадров), по замечанию куратора:
  1) editor.js ensurePreloaded: для входа в режим нужны только кадры его окна (batchModeInstNumber) вокруг
     текущего, а не вся сцена. После снижения MaxWorldNumber до 20 прежнее условие на сценах длиннее 20 кадров
     не выполнялось никогда, режим не открывался ("Loading scene in background").
  2) side_view_op.js: перехват правой кнопки (сдвиг вида) отключён внутри #batch-box-editor - он глушил
     контекстное меню кадра, из-за чего нельзя было интерполировать или удалить коробку в одном кадре.
  Проверено событиями мыши: правый щелчок выбирает нужный кадр и открывает меню, удаление и интерполяция
  на один кадр через меню работают.
- side_view_op.js: рамка-манипулятор в окошках коробки при сдвиге вида по вертикали ехала зеркально коробке
  (знак смещения). Проверено измерением проекции центра коробки против центра рамки во всех трёх окошках.
- Вид сверху в окошках коробки: щелчок по соседней коробке выбирает её (самую маленькую из содержащих точку
  щелчка, чтобы столб внутри большой коробки выбирался). Щелчок по ручкам рамки и в пакетном режиме не трогается.
- box_editor.js: при изменении размера панели окошек (растягивание за угол) делается полное обновление редактора:
  раньше рамка-манипулятор и камера окошка оставались под старый размер до следующего действия.
- Зум колесом в главном окне (по замечанию пользователя: зум залипал, карта резко разворачивалась):
  OrbitControls.js - камера и цель вращения сдвигаются вдоль луча на точку под курсором в одной пропорции,
  направление взгляда не меняется, точка под курсором остаётся под курсором; editor.js - поиск точки под
  курсором кэшируется на 0.4 с (поиск по облаку ~20 мс, без кэша события колеса копились).
