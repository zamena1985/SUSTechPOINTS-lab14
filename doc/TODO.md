# Список доработок

Что планируется сделать, в порядке приоритета. Сделанное переносится в CHANGES.md.

1. **Выбор объекта щелчком в окошке коробки.** Сейчас окошки показывают только выбранную коробку, соседние
   рисуются для ориентира. Нужно: щелчок по соседней коробке в виде сверху делает её выбранной.
   Сделано в ветке `develop`, ждёт проверки в работе и слияния в `main`.
2. **Группа коробок: Shift+щелчок, J дублировать, W/A/S/D/Q/E/Delete для всей группы.** Нужно для повторяющихся
   объектов (секции стеллажей, ряды труб). Сделано в ветке `develop`, ждёт проверки в работе и слияния в `main`.
3. **Скриншоты гайда.** В картинках есть кадры выданной сцены. Если куратор против публикации, переснять
   на примерной сцене авторов (`data/example`) или вынести иллюстрированную версию во внутреннее облако.
4. **Проверка на Windows 10.** Портативная версия проверена на чистом ноутбуке с Windows 11.
   Для Windows 10 нужна виртуальная машина или ноутбук.
5. **Pull request авторам.** Общие исправления (отмена, клавиши в любой раскладке, Q/E в окошках,
   камера, необязательный TensorFlow) можно предложить в оригинальный репозиторий. Авторы не отвечают
   с 2024 года, поэтому без спешки.
6. **Ветка dev.** Пока один разработчик, работа идёт в `main`, релизы по тегам. Завести `dev`, когда появится
   второй участник.
