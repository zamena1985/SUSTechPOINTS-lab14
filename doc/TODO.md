# Список доработок

Что планируется сделать, в порядке приоритета. Сделанное переносится в CHANGES.md.

Выпущено в v1.1 (02.11.2026): выбор соседней коробки щелчком в виде сверху, группа коробок (Shift+щелчок, J),
подписи за коробкой, наклон в боковых окошках, авто-разметка без TensorFlow, run.bat с ожиданием сервера.

1. **Скриншоты гайда.** В картинках есть кадры выданной сцены. Если куратор против публикации, переснять
   на примерной сцене авторов (`data/example`) или вынести иллюстрированную версию во внутреннее облако.
2. **Проверка на Windows 10.** Портативная версия проверена на чистом ноутбуке с Windows 11.
   Для Windows 10 нужна виртуальная машина или ноутбук.
3. **Pull request авторам.** Общие исправления (отмена, клавиши в любой раскладке, Q/E в окошках,
   камера, необязательный TensorFlow) можно предложить в оригинальный репозиторий. Авторы не отвечают
   с 2024 года, поэтому без спешки.
4. **Ветка dev.** Пока один разработчик, работа идёт в `main`, релизы по тегам. Завести `dev`, когда появится
   второй участник.
